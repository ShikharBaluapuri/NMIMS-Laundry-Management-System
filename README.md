# NMIMS Laundry Management System

A comprehensive Laundry Management System designed for NMIMS university hostels and campus facilities.

## Features
- Student authentication and laundry slot booking
- Real-time laundry status tracking (Received, Washing, Drying, Ready for Pickup)
- QR Code / Token generation for laundry drop-off & pick-up
- Admin / Laundry staff management dashboard
- Automated notifications & alerts

## Tech Stack
- Mobile App / Frontend
- Backend API
- Database
